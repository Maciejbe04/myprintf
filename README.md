# myprintf

1. ### ***Done*** :<br>

	- d or i	Signed decimal integer<br>
	- u	Unsigned decimal integer<br>
	- o	Unsigned octal<br>
	- x	Unsigned hexadecimal integer<br>
	- X	Unsigned hexadecimal integer (uppercase)<br>
	- c	Character<br>	
	- s	String of characters<br>	
	- p	Pointer address<br>	
	- n	Nothing printed. The corresponding argument must be a pointer to a signed int. The number of characters written so far is stored in the pointed location.<br>	
	- %	A % followed by another % character will write a single % to the stream.<br>
